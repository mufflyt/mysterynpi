WHY THIS FILE EXISTS
The canonical name primitives were found as UNCOMMITTED working-tree state, not
as a published implementation. Promoting untracked code to canonical without
recording where it came from is how a repository acquires an authority nobody
can trace. This records provenance BEFORE recovery, so the merge can be audited
rather than trusted.

Untracked generated .Rd files are NOT evidence that an implementation is
canonical, and are not treated as such here.
