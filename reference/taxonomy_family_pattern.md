# Expected taxonomy pattern for a board specialty, or \`NA\`

Expected taxonomy pattern for a board specialty, or \`NA\`

## Usage

``` r
taxonomy_family_pattern(specialty)
```

## Arguments

- specialty:

  character vector of board-specialty labels.

## Value

character vector of prefix patterns, \`NA\` where no expectation is
defined.
