# Normalised key with absence rendered as \`""\`, for use as a join key.

Normalised key with absence rendered as \`""\`, for use as a join key.

## Usage

``` r
blank_na(x, strip_alternates = TRUE)
```

## Arguments

- x:

  character vector.

- strip_alternates:

  see \[name_key()\].

## Value

character vector, \`NA\` mapped to \`""\`.
