# Confidence labels for an accepted NPI match

\`NPI_MATCH_CONFIDENCE_LEVELS\` is the stable vocabulary returned by
\[grade_npi_match_confidence()\]: \`high\`, \`medium\`, \`low\`,
\`ambiguous\`, and \`unmatched\`.

## Usage

``` r
NPI_MATCH_CONFIDENCE_LEVELS
```

## Format

A character vector of five labels in reporting order.
