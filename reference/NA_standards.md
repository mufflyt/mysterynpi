# NA_standards

Every standard assessed as not-applicable, with the reason. \`srr\`
wants these recorded in the source rather than argued in a review
thread, and the full assessment that produced them – all 145 individual
verdicts, with counts per subsection – is in
\`srr/standards-compliance.md\`.

THE SHAPE OF THIS PACKAGE, stated once so the NA verdicts below read as
a consequence rather than as evasion: \`mysterynpi\` is record-linkage
machinery. It decides whether two records name the same person using
deterministic rules. Nothing is estimated, nothing iterates to
convergence, there is no model object, no coefficient, no residual, no
series and no forecast. The standards that assume any of those are not
standards this package can fail; they are standards about software it is
not.
